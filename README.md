## Proyectos destacados

### Software Avanzado — Plataforma de servicios bancarios

Proyecto académico basado en una arquitectura de microservicios para la gestión de clientes, cuentas, pagos, transacciones y notificaciones.

El proyecto utiliza comunicación asíncrona mediante RabbitMQ, contenedores Docker, Kubernetes, API Gateway y diferentes servicios independientes.

También he trabajado en aspectos relacionados con CI/CD, despliegues progresivos, pruebas y automatización.

**Tecnologías:** Java / TypeScript, NestJS, Docker, Kubernetes, RabbitMQ, REST APIs, GitHub Actions.

---

### GitOps, entrega progresiva y seguridad de la cadena de suministro

Proyecto enfocado en implementar un flujo de despliegue basado en GitOps.

Se trabajó con un repositorio de aplicación y un repositorio independiente para la configuración de despliegue. ArgoCD se utiliza para sincronizar los cambios y Argo Rollouts para realizar despliegues progresivos mediante estrategia canary.

También se implementaron herramientas y políticas relacionadas con seguridad de la cadena de suministro y validación de recursos.

**Tecnologías:** GitHub Actions, Docker, Kubernetes, Helm, ArgoCD, Argo Rollouts, Terraform, Trivy, Cosign, Kyverno y Sealed Secrets.
